> 旧データには架空生成ロジックによる値、血統の過剰な固定値、休養週数の一律設定、架空推定オッズ、紐づかない払戻などが確認されています。

- アプリ画面、特徴量キャッシュ作成、バックテスト、Discord推薦通知にはこの停止処理を接続しています。

- このリポジトリとユーザーPCの KEIBA_AI_Windows_Beta は別管理のため、GitHubの変更だけでWindows常駐ワーカーが更新されたとは扱いません。

## 取得し直す必要があるデータ

**レースごと**：JRAレースID、実開催日、競馬場、距離、芝ダート、内外回り、発走時刻、馬場状態、天候、勝馬・着順、払戻。

**出走馬ごと**：正規馬ID・馬番、騎手ID、調教師ID、年齢、斤量、過去走、脚質、馬体重。

**取得の証拠**：許可されたソース（例：JRA-VAN JV-Link）の原本・取込時刻・レコード識別子・改変検知ハッシュ。発走前の予測情報と確定後の着順・払戻を区別する。

**いずれかが未確認なら未確認のまま残します。** 根拠なく「晴」「良」「キズナ」「4週間」「15倍」などと補完しません。

## 検証方式

同じ学習日付・同じ評価レースID・同じ1レース本命1頭で全モデルを比較。複合条件を発見する期間と検証期間は分離し、発走前に取得できた情報しか入力しない。人気1位との比較も同じレース群で実施。回収率は発走前オッズと実際の払戻が確認できる場合のみ計算。
