# 🏇 KEIBA AI -- 競馬AI予想＆リアルタイム期待値分析システム

過去の実績データ集積と機械学習（LightGBM）を融合し、発走前オッズとAI勝率から期待回収倍率をリアルタイム分析・自動通知するWindows向け競馬AIシステムです。

---

## 🌟 主な機能

### 1. レース情報の自動取得＆発走前オッズ追記保存
- 当日の開催レース情報（発走時刻、出走馬、馬番、騎手、斤量、単勝オッズ等）を取得。
- 公式・認可データソース（JV-Link / 認可フィード）に対応。
- **安全方針（Fail-Closed）**: 未接続または取得不能時は架空データや確定オッズで代用せず、厳格に「未接続・欠損扱い」として記録・表示します。

### 2. AI単勝勝率予測（LightGBM 28特徴量）
- 単勝1着専用モデル（`models/keiba_lgbm_win_v2_28cols.joblib`）による予測勝率を算出。
- **数学的整合性**: 単勝勝率と複勝確率（3着以内）を明確に分離し、`P(Win) <= P(Top3)` 制約およびレース内合計1.0の正規化を保証。
- **未来リーク完全排除**: 着順・確定オッズなどの事後データが含まれる特徴量は安全装置により自動遮断。

### 3. 期待値（EV）分析＆リアルタイムランキング
- `期待回収倍率 = AI単勝勝率 × 単勝オッズ`
- 対象レース内の全出走馬を期待値順に自動ランキング。
- オッズ観測日時・取得日時をタイムスタンプ付きでSQLite（`data/odds_history.db`）に追記保存。

### 4. 直感的なWindows Webダッシュボード（Streamlit）
- 日本語UIで専門知識がなくても操作可能。
- 表示項目:
  - 🏁 本日の開催レース一覧・発走時刻
  - 📋 出走馬一覧・騎手・斤量
  - 🧠 AI単勝勝率 ＆ 単勝オッズ
  - 🔥 期待回収倍率 ＆ 注目馬ピックアップ
  - 📡 データ取得状況・最終更新時刻
  - 📊 過去レース分析・バックテスト・特徴量分析

### 5. 自動通知（Windowsトースト通知 ＆ Discord通知）
- アプリ画面を開いていなくても、条件を満たすレースを自動通知。
- **Windowsネイティブトースト通知**: PowerShell経由でデスクトップにポップアップ通知。
- **Discord通知**: Webhook連携によるスマホ・PCへのプッシュ通知。
- **重複防止**: 同一レース・同一タイミングの通知を安全に抑止。
- **安全ロック**: モデル・実データの完全検証が完了するまで、実際の推奨通知は安全にレビュー専用（無効化）としてフェイルクローズ。

### 6. バックグラウンド自動実行（アプリ終了中も監視継続）
- **常駐デーモン (`scripts/run_background_monitor.py`)**: 画面（Streamlit）を閉じていてもバックグラウンドで60秒ごとに定期スキャン・AI推論・通知チェックを実行。
- **Windowsタスクスケジューラ登録 (`scripts/setup_windows_task.bat` / `.ps1`)**: Windowsログオン時またはPC再起動後も自動で定期監視を復帰。
- **耐障害性**: ネットワーク切断やデータ異常が発生してもログに記録し、クラッシュせず次回サイクルで自動復旧。
- **SQLite同時アクセス安全性**: WALモード（Write-Ahead Logging）とビジータイムアウトにより、UIと監視プロセスの同時アクセスロックを完全に防止。

## 🚀 起動方法

### ワンクリック起動（推奨）
リポジトリ直下の **`START_KEIBA_AI.bat`** をダブルクリックするだけです。
1. Python環境を自動認識
2. 常駐バックグラウンド監視デーモンを最小化ウィンドウで開始
3. ブラウザで自動的に操作ダッシュボード（`http://localhost:8501`）が開きます

### Windowsタスクスケジューラへの登録（PC再起動後も常時自動監視）
```powershell
# 5分間隔で定期実行タスクを登録
powershell -ExecutionPolicy Bypass -File scripts\setup_windows_task.ps1 -Action register

# 稼働状況を確認
powershell -ExecutionPolicy Bypass -File scripts\setup_windows_task.ps1 -Action status

# 登録解除
powershell -ExecutionPolicy Bypass -File scripts\setup_windows_task.ps1 -Action unregister
```

## ⚙️ 初期設定・通知設定

### Discord通知の設定
1. アプリ左側サイドバーの「🔔 Discord通知設定」に Webhook URL を入力。
2. 「💾 URL保存」をクリック。
3. 「🧪 テスト送信」をクリックしてスマホ・PCに着信すれば完了です。

### Windowsデスクトップ通知の確認
1. サイドバーの「🔔 デスクトップ通知テスト」をクリック。
2. Windows画面右下にトースト通知が表示されます。

### 通知条件の設定
アプリ内の「🏇 本日レース・AI期待値速報」タブで以下を設定可能：
- 最小期待回収倍率（デフォルト: `1.15`）
- 最小AI勝率（デフォルト: `20%`）
- Windowsトースト通知 ON/OFF
- Discord通知 ON/OFF
