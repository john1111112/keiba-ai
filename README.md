# 🏇 AI競馬予想システム（過去データ集積型）

過去のレース結果や出走馬データを集積し、機械学習（LightGBM）で勝率・好走率・期待値を予測する競馬予想Webアプリケーションです。

---

## 🌟 主な特徴

1. **過去データの自動集積基盤（SQLite）**
   - レース諸元（競馬場、距離、馬場状態、天候）
   - 各馬成績（着順、走破時計、上がり3F、単勝オッズ、斤量、馬体重増減）
   - 騎手・調教師の成績
2. **競馬特化の特徴量エンジニアリング**
   - 過去成績のローリング集計（前走着順、前走上がり3F、過去平均着順、過去複勝率）
   - 騎手・調教師の過去勝率・複勝率
   - 斤量体重比（負担重量 / 馬体重）
3. **LightGBM による高精度予測**
   - 複勝圏内（3着以内）好走確率の予測（AUC 0.89+）
   - 「好走確率 × 単勝オッズ」による期待値算出
   - 予想印判定（◎本命、○対抗、▲単穴、△連下、☆穴馬）
4. **バックテスト＆回収率検証**
   - 過去レースでAIの予想通りに購入した場合の回収率（単勝・複勝・馬連）を自動シミュレーション
   - 累積損益カーブや重要度スコアのグラフィカル表示
5. **直感的なWebダッシュボード（Streamlit）**
   - ブラウザからワンクリックでデータ集積、モデル再学習、レース予想が可能

---

## 🚀 起動方法

### 方法1: バッチファイルをダブルクリック
フォルダ内の `run_app.bat` をダブルクリックするだけで自動的にブラウザが起動します。

### 方法2: コマンドラインから起動
```bash
cd C:\Users\user\.gemini\antigravity\scratch\keiba-ai
python -m streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。

---

## 📁 ディレクトリ構成

- `app.py`: Streamlit Webアプリケーション本体
- `run_app.bat`: ワンクリック起動用バッチファイル
- `data/keiba.db`: 過去データを集積したSQLiteデータベース
- `models/keiba_lgbm.joblib`: 学習済みLightGBMモデル
- `src/`
  - `database.py`: DB操作・集計・保存
  - `scraper.py`: netkeibaスクレイピング＆データ生成
  - `features.py`: 特徴量抽出・前処理パイプライン
  - `model.py`: LightGBM学習・推論・印付け
  - `backtest.py`: 回収率シミュレーション
