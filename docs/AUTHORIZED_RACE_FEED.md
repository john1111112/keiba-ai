# Authorized race feed integration

This integration fetches race schedule, runners, start times and pre-race win
odds **only from an explicitly authorized JSON HTTPS endpoint**. It does not
scrape third-party sites, create synthetic odds, or claim provider certification.

## Configure

Set environment variables `KEIBA_FEED_URL` (licensed HTTPS JSON endpoint)
and `KEIBA_FEED_TOKEN` (the provider's API token) in the Windows environment.
Do not commit tokens to GitHub.

Run from the project root:

```powershell
python -m scripts.fetch_authorized_races --out-dir data/authorized_feed --attempts 3
```

The API must return exactly this JSON structure:

```json
{
  "published_at": "2026-10-27T11:59:00+09:00",
  "races": [
    {
      "race_id": "20261027-race-01",
      "race_time": "2026-10-27T13:00:00+09:00",
      "race_status": "upcoming",
      "horses": [
        {
          "horse_number": 1,
          "horse_name": "Example Horse",
          "win_odds": 4.2,
          "odds_observed_at": "2026-10-27T11:58:00+09:00"
        }
      ]
    }
  ]
}
```

The example is a **schema illustration, not live race data**. Unknown odds
must be `null` and their `odds_observed_at` must also be `null`.

Outputs: `snapshots/<UTC receipt timestamp>.json` (timestamped evidence),
`upcoming_races.json` (schedule-only scanner input),
`last_feed_status.json` (last successful fetch). Failed fetches do not
overwrite the last successful schedule. Retries use exponential backoff.

**Not complete until a real contractually authorized endpoint and token are
provided and tested.** HTTPS and the returned timestamps are insufficient
to independently certify the publisher, feed rights, or model quality.
No bet recommendation, AI probability or EV is generated by this module.
