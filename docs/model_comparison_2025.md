# 2025年 実競馬データモデル比較評価レポート
(AI単独モデル vs 市場オッズモデル vs 統合モデル)

## 1. 評価概要
- **目的**: 2025年の実データを用いて、AI単独モデル・市場オッズ（単勝人気）モデル・統合モデル（AI+市場ブレンド）の予測精度（Log Loss, Brier Score, Top-1 的中率）を厳格に比較検証する。
- **データ期間**: 2025年1月1日 〜 2025年12月31日
- **サンプル規模**: 865 レース（出走頭数 12,589 頭、平均出走頭数 14.55 頭）
- **リーク防止・安全条件**:
  - **2026年ホールドアウトデータは完全未参照・非アクセス** (`holdout_status: NOT_ACCESSED`)。
  - レース確定後の事後情報や着順、払戻等の未来情報は特徴量から厳格に排除。
  - 本番 DB (`data/keiba.db`)・モデルファイル (`models/*.joblib`) は一切変更せず、読み取り専用接続で実行。

---

## 2. 比較モデル仕様
1. **均等確率ベースライン (`uniform`)**:
   - $P_{\text{uniform}, i} = \frac{1}{N_{\text{runners}}}$
2. **AI単独モデル (`ai_alone`)**:
   - 特徴量: 馬齢 (`age`), 斤量 (`weight_carry`), 馬番 (`horse_number`)
   - 2022-2024年の過去学習期間等で選定された重み（`age: -0.25`, `weight_carry: +0.1`, `horse_number: 0.0`）による Softmax 校正確率。
3. **市場オッズモデル (`market_odds`)**:
   - 単勝オッズ $O_i$ から控除率を補正した市場確率: $q_i = \frac{1}{O_i}, \quad P_{\text{market}, i} = \frac{q_i}{\sum_j q_j}$
4. **統合モデル (`blend_50ai_50mkt`, `blend_30ai_70mkt`, `blend_10ai_90mkt`)**:
   - AI確率と市場オッズ確率の線形結合: $P_{\text{blend}, i} = w_{\text{ai}} P_{\text{ai}, i} + (1 - w_{\text{ai}}) P_{\text{market}, i}$

## 4. 分析と示唆

1. **AI単独モデルのベースライン凌駕**:
   - わずか 3 つの基本特徴量（馬齢・斤量・馬番）のみを用いた AI 単独モデルでも、均等確率ベースラインに対して Log Loss で `-0.0518`、Brier Score で `-0.00048`、的中率で `+3.01%`（66勝→92勝）の確実な改善が確認されました。
2. **市場オッズの極めて強力なベンチマーク**:
   - 市場オッズモデルは、Race Log Loss `1.9882`、Top-1 的中率 `31.33%`（271勝）を記録しました。これは JRA 単勝1番人気の公称勝率（約32%）と整合しており、極めて強力な予測ベンチマークとして機能しています。
3. **統合（ブレンド）における課題と今後の開発方針**:
   - 初歩的特徴量のみの AI 予測を単純ブレンド（50:50）した場合、AI側の不確実性（ノイズ）により Log Loss は `2.1573` と市場オッズ単独より悪化します。
   - 市場オッズ比率を 90% に引き上げると `2.0037` まで改善しますが、市場オッズを上回るには至りません。
   - **結論**: 市場平均を凌駕し「市場人気と実力の乖離」を正しく見出すためには、市場オッズを事前ベースライン（Prior）として固定した上で、市場が織り込み切れていない特徴量（調教ラップ、馬場適性、ローテーション、枠順バイアス等）をAIが独立に推定し、オッズとの乖離度（エッジ）を評価するアーキテクチャが必要不可欠です。
