> - 記載された情報は 2026年10月25日 時点の公開一次情報に基づく候補調査結果であり、**特定事業者との契約締結や利用許諾を意味するものではない**。
> - 確認が取れていない利用条件・許諾範囲は推測で補完せず、すべて **「未確認」** と明記する。
> - 無料で合法的に利用可能な公式のリアルタイム発走前オッズ自動取得APIは存在が確認されておらず、推測で捏造してはならない。

## 3. 現存データの権利・出所棚卸し (Data Provenance & Isolation Audit)

プロジェクト内の既存データソースの出所と利用可否を棚卸しし、以下の通り隔離・除外方針を確定する。

1. **既存DB `data/keiba.db` の payouts テーブル (6,512件)**:
   - **出所**: 過去フェーズで確認された架空・テスト用データ。
   - **判定**: **完全隔離・評価除外**。オフライン評価やモデル学習に一切使用しない。
2. **races / race_results テーブル**:
   - **出所**: 過去の収集経緯において公式出所証明・ライセンスが未確定のデータが含まれる。
   - **判定**: **保留・本番評価除外**。出所真正性が客観的に証明できないデータは、真の回収率検証には使用せず、パイプラインの動作検証用フィクスチャとしてのみ取り扱う。
3. **Phase 10〜12 で整備されたローカルレシート・フィクスチャ**:
   - **出所**: 明示的に生成されたローカル検証用合成データ。
   - **判定**: **採用（パイプライン検証用）**。ただし「合成データの成績であり、実運用回収率ではない」免責を必須とする。

## 4. ゼロコスト開発方針と次の意思決定 (Zero-Cost Roadmap)

1. **現段階（Phase 13）の決定**:
   - 費用0円の範囲を維持するため、外部有料APIの契約やJRA-VANの登録は行わない。
   - 時系列分割によるリークフリーのオフライン評価パイプラインを合成フィクスチャで確立する。
   - 発走前オッズと確定払戻が公式照合できないデータセットに対しては、**「回収率・的中率は評価不可（Unevaluable）」** と正しく判定・出力する。
2. **次フェーズ以降の意思決定候補**:
   - オプション A: JRA-VAN Data Lab. の初回1ヶ月無料枠を活用した公式検証（要アカウント作成・手動手続き）。
   - オプション B: 完全ローカル合成データによるモデル改善とペーパー運用の模擬検証継続（費用0円・契約不要）。
